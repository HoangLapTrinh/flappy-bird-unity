# Flappy Bird - Unity

A Flappy Bird-style game developed using Unity and C#.

## Features

- Player movement and gravity
- Pipe spawning
- Collision detection
- Score system
- Game over and restart system

## Technologies

- Unity
- C#
- Visual Studio

## Project

This project was created as a learning project to practice basic game development with Unity and C#.

## What I Learned

- Writing C# scripts in Unity
- Working with Unity physics and collisions
- Managing game states
- Implementing a basic scoring system
- Debugging and testing a game project
